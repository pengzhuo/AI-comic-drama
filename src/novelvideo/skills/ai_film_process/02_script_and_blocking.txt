剧本、人物与分镜

前置与阶段按00；缺资料先列缺口。字段可用中文表格/列表，英文ID为可选标记，不限定软件。

本模板负责剧本理解、导演边界、人物补全、空间图、分集和逐镜分镜要求。提示词只能编译已通过的分镜。

剧本理解检查

锁定版本后按叙事顺序读完全文；长稿可分段，但须记录覆盖范围并确认所有场次、动作、对白、旁白、画外对白、OS和结尾。不得用梗概、搜索命中或前几场代替。先建立原文事实账本，不以摄影设想、类型经验或资产外观补因果；完成事实理解后，仍在步骤2内按下节补全制作安排并交付结构化剧本，不能读完对白就开跑。

script_understanding_version 至少含：题材/时代/人物关系/情绪/节奏；现实、回忆、梦境等叙事层与时间线；人物别名、首次视觉出现、各时点知情/未知/误解；逐场“谁→对谁/什么→做什么→触发→结果”；全部声音的说话人、受话人、可听见对象；场景、道具、服装、伤势、位置和状态变化；秘密/谎言/猜测/真相及揭示边界；开场、转折、高潮、结局/钩子；会改变执行的歧义及原文位置。

建立两个权威账本：

source_id → 原文位置 → 场次/事件/节拍 → shot_id → 声音事件 → 成片时间段
line_id → 说话人 → 对白/旁白/画外对白/OS → 原文全文 → 可听见对象

连续状态链：按连续时间段登记人物位置／姿态／朝向、手持物、动作进度、知情状态、画外状态、声音游标、场景状态与世界光源；无原文变化时继承上段出口。现实／回忆／回想只在剧本实际呈现时标注原文依据与精确范围；凝视、思考、提及过去或OS本身不代表进入回忆，梦境／想象单独标记。资产清单登记场景、出镜角色及跨镜反复出现或剧情关键的道具，并在分镜完成后映射到shot。普通一次性背景细物不另造资产，不为“用完资产”强塞素材。

从开场正向复述因果，再从结局/钩子反查前置原因。全文覆盖、因果、知情边界、叙事层、声音归属、揭示顺序和结局无执行性歧义后，才记录 script_understood。

步骤2：先优化补全，再放行制作剧本

本阶段交付的是可直接阅读、逐场执行的完整制作剧本，不是问题清单、几句建议或提前写好的分镜提示词。原稿完整保留；制作剧本把原剧情／原声轨与有来源标记的空间、活动、动作、光线放在一起，供后续唯一读取。已有完整合格剧本也必须检查，缺项才补，不无故改写。

读审与补全顺序

1. 读完整稿、核对事实：完成上节因果、声音、关系和知情账本，识别代词不清、动作跳步、到离场不明、接触不成立、光线或连续状态矛盾。心理描写留在原稿依据中，制作栏转成有依据的可见／可听表达；不能把未知内心写成确定事实。
2. 逐场排清基础空间：锁场景／时段／内外、参与者及开场状态，明确谁在谁的哪一侧、面对谁、距离能否支撑原文互动。统一用固定世界地标／方向，不能只写随镜头改变的“画面左边”。普通场景简明文字即可；仍有多种影响执行的解释，先做文字草图或非生成式俯视示意。无法解决则阻断本阶段，不推给后续AI猜。
3. 补清正在做什么及动态：对白前先写各人在干什么；逐节拍写谁受何刺激、做什么、从哪里经哪里到哪里、动作结束是什么姿态。原文没有移动就明确原位说话／倾听，不为“有动作”强加端杯、翻手机、走来走去。原有活动可持续；停下、转身、起身、离开须有触发及前后状态。未发声、画外与群组人物也要有适用状态，不能随台词轮次消失。
4. 补清基础光线：用一句至数句写光从哪里来、朝哪里照、整体明暗和软硬／冷暖大意；记录会随剧情开关或移动的光源事件，无变化写保持。优先原文／既有场景依据；缺失且不影响剧情时选最少、普通、空间成立的方案并标制作补充，不凭空添加剧情可见灯具、特殊天气、霓虹／彩光。此时不需摄影设备、精确色温／照度或色卡；世界光源位置／方向在此锁定，后续风格只细化质感，不借风格换光位或改变昼夜。
5. 改写为统一格式并复核：按本节“制作剧本填写格式”输出全稿；拆清主体、对象、动作和声音，使用固定角色／场次／节拍ID与短句，明确同时或先后。只改变表达和组织，不删事件／台词，不加快节奏，不把每句台词拆成一个镜头。事件有接触时写清起点、接触、结果；不相关的微小肌肉动作不用填满。

什么可直接补，什么必须先解决

|缺口或修改|执行方式|边界|
|---|---|---|
|原文已有位置／动作／光线|提取并写清，继承跨场连续状态|不能为顺手拍摄改站位、时段、持物、动作结果|
|原文未写的非剧情站坐、朝向、普通相对距离、无叙事作用的环境光安排|综合全文和既有材料，选一个最小可行方案，写入制作补充与修改表；不逐项问用户|补充不能改变偷听／遮挡／可达性、亲疏含义、先后知情、出口阻断或其他因果；锁后必须继承|
|概括动作或代词不清，但依据唯一|换成明确角色／对象，展开必要连接，留source_id；台词内部代词和标点原样保留|不把“递给”写成“扔给”，不替换对象、胜负或结果|
|位置、地点、时间、动作目的／对象等缺失，存在会改变剧情的不同解释；或原文自相矛盾|先完成不依赖它的整理，给出具体缺口、受影响场次和建议改法，只问最窄问题；受影响剧本未定不得通过总门|例如仅两句对白无法知道室内／室外且影响剧情，不能套默认客厅、白天或自行虚构人物关系|
|需要改事件、关系、因果、信息揭示、台词／标点、说话人、声音类型、结局或新增关键道具|已有明确改稿授权则在该范围落实并记录修订；否则给可审阅的具体改稿，待确认后形成新原稿版本|本次“优化可读性与基础调度”的授权不等于任意重写故事；不强加冲突、反转、钩子或台词润色|

来源至少分为“原文事实／有依据推断／制作补充／用户确认修改”，附来源位置或补全理由。影响执行的推断必须核定为明确方案或提问解决；不能带着“也许站着”“光线待定”“模型自行发挥”放行。纯身份履历或后续摄影细节可留待所属阶段，但不影响本场可执行性。非剧情位置／基础环境安排属于本节明确允许的制作补充，不被其他章节的“不得新增场景／道具／光线”误解为连空白都不可补；已有事实及叙事关键物件仍不可擅改。

唯一制作剧本与放行门

同时交付：①完整结构化制作剧本；②原稿→场次／节拍／line_id覆盖映射；③“原缺口→补全内容→来源／理由→影响范围”修改表；④未决项与逐场检查结果。正文先给简短可读描述，管理字段放场次头／表，不用密集ID代替中文表达。全稿保留原文全部声音文字及标点，不把对白改成“同原文”链接或摘要。

记录 source_script_version / production_script_version / scene_baseline_version / script_ready_gate=passed|failed|blocked。每场必须可直接回答：何时何地、谁在场、各自在哪里／朝哪里、正在干什么、怎样发生变化、光从哪里来、如何结束并衔接下一场。场景切换须记录scene_transition_id、前场已发生的推动事件、下一场到达目标／时间依据及新场开局状态；不得臆造旅行或事件。逐项给“原稿依据或补全理由→实际正文位置→核对结果”，全场覆盖且执行性未决项为零才可passed；已有矛盾为failed，缺依据／必要答案为blocked。script_understood不能替代script_ready_gate；只有对白、只有诊断、只有空模板或仅标“已理解”均不通过。

script_ready_gate是步骤2内的内部制作复核，不新增第17阶段，也不要求用户逐场审批；只有上表所列实质剧情歧义／越权修改才集中确认。普通补全在本流程授权内完成并展示。锁版前不启动人物资产、场景资产、风格生产、分镜或视频，能力测试也不能绕过此门；本阶段无需等待未来资产、声音母版、镜号、机位或最终色卡，避免循环依赖。

后续只消费当前已通过制作剧本，同时以原稿核对剧情／台词；制作补充以production_script_version为权威依据。步骤3补人物设定，步骤5细化光质与风格，步骤6细化尺度、地图、mark与摄影机，步骤8拆镜，均继承这里的基础安排。若需改变已锁站位、路径或世界光源，先修制作剧本和scene_baseline_version，复核受影响场次及下游，再推进；不能后续各改一套。不把尚未生成的画面当作剧本已实现的证据。

制作剧本填写格式

【项目与版本】
原稿名称／source_script_version／全文位置：
制作剧本名称／production_script_version：
处理范围：哪些集／场；是否已覆盖所需全文
本次已获改稿授权：范围或“仅结构整理与不改变剧情的制作补全”
人物称呼表：角色ID＝固定称呼；别名及依据
场次目录：场次ID、标题、原文范围、时间／地点及连续关系

【场次 S01：简短场名】
来源：source_id及原稿位置
基础版本：scene_baseline_version
时空：地点、内／外、时段；与前场为连续／原文有据的时间变化
本场发生什么：谁对谁做什么，已有问题怎样推进或落地；不另造冲突

【空间与光线】
固定参照：用地标／约定世界方向说明区域、入口、必要通路与接触面
光线：光源所在位置→照射方向；整体明暗、软硬／冷暖大意
变化：本场光源保持，或哪个已有事件导致何时改变
来源标记：原文事实／有据推断／制作补充／用户确认修改

【开场人物状态】
角色：在哪里，距离谁多远，站／坐／其他姿态，身体朝向、看向谁
正在做什么：已有活动或原位说话／等待／倾听；手上是否有原文物件
在场与知情：在场／尚未到场／隔区／画外，谁能听见；依据
其余参与角色同样填写；群组可按区域记录，不新造逐人身份

【节拍 B01】
前置／触发：已有动作或实际到达的信息，先后关系明确
动作：角色＋动作＋对象；移动时写起点→通路→终点＋结束姿态
同时发生：另一角色继续什么；不发声不等于消失
声音：line_id｜说话人｜现场对白／画外对白／OS／旁白｜原文逐字全文
听见范围与反应：谁收到哪段信息后，出现什么有依据的可见变化
结果：此节拍后位置、姿态、持物／接触状态有无改变
来源：原文范围；新增制作安排明确标记
后续节拍按需重复；不以一句对白或一次眨眼强制划一拍

【场末与衔接】
每人最后位置、姿态、活动／持物与必要情绪状态：
原文事件结果与未完动作：
下一场关系：原文连续／时间地点改变／已给结尾
换场因果（如适用）：scene_transition_id｜前场已发生的推动事件｜下一场到达目标／时间依据｜新场开局状态；无原文支持不得补造
未写离场不得补离场；结尾没有钩子不得补反转

【补全修改表】
原位置／缺口｜补全后的具体文字｜类别／理由｜是否影响剧情｜采用依据

【本稿检查】
原文事件覆盖：source_id→scene_id／beat_id
声音覆盖：line_id→原文全文／说话人／类型→本稿位置；无漏改重复
逐场：时空、全员位置、当前活动、动态／终态、光线、连续性均明确
未决项：问题、受影响场次、具体建议及所需答案；没有则明确写无
script_ready_gate：passed／failed／blocked；逐项正文位置与核对依据

未适用项写“不适用＋理由”，例如无移动就写“保持原位”，不硬编路线；身份完整背景、精确光学参数、镜号、镜长和实际素材ID留给后续阶段。执行必需项不能空着或写“后面自由发挥”。发声类型沿原稿，不能把心理描述自行变成OS，也不能把现场对白自行改成旁白。

导演边界

不得改变事件、因果、时空、关系、信息范围、动作主体/对象/结果、台词/标点/顺序/说话人/声音类型、道具、伤势、服装、场景文字、结局或钩子。可在不产生新剧情事实的前提下设计倾听、停顿、呼吸、视线、微反应、动作连接、景别、机位、构图、焦点、运镜、真实光源和声音；写入制作剧本的制作字段，保留来源标记，不覆盖原稿或伪称原文事实；步骤2允许的非剧情空白补全按上节执行。

原文已给位置/姿态/结果时保持。概括动作（如拿取、保护、看望）须展开为可执行的视线、手部、路线和起止姿态，并标“制作调度”；这不授权新增行为。未规定的站坐须在步骤2制作剧本中设定并锁定，之后不得无过程换位。忠实原文不等于人物只能站立、眨眼或念旁白。完整基础调度不要求全员同时入画：后续可用中近景观察当前关键人物，其余人物保留画外位置、活动、发声与路线。减少全景只改变取景，不能把原文站立改坐下、删人、挪位或改动作。

人物卡（缺项才补）

script_ready_gate通过后检查制作剧本、既有人物设定和已有锁定资产；不能把本应在步骤2补清的当前位置与活动拖到本环节。核心角色无设定时建完整卡，缺什么补什么，完整则复用；一次性背景人物只需最小身份/外观，故事无反派不强造反派。具体外观、材质和色彩待时代、摄影风格与色卡确定后锁定。

每项标注：原文事实（带source_id）、剧本推断（依据与不确定性）、制作补充（不改因果的外观/表演/声音选择）或未明确/不适用。不得为补全而虚构亲属、创伤、职业、死因、精确年代、诊断、隐秘动机；若影响执行才提最窄问题。不得新增口头禅、伤疤、身份标志或道具。

人物卡包含：

- 身份/外观：character_id、称呼、版本、年龄段、故事作用、社会处境、稳定辨识特征、服装/伤病状态；精确无依据项留空。跨年龄用 age_stage_id 分开身份锚点与成长/衰老/病程变化。
- 性格/变化：2—3个有行为证据的特征与矛盾面；愿望、需要、恐惧、盲点、压力策略、社会面具；已知经历、原文转折与终点，不强迫每人有成长弧。
- 习惯／表演：在01B分镜与表演部分的唯一acting_profile_id中维护行为基准；有依据时可选少量候选习惯（通常不超过2—3项），也可不设。记录来源、触发、不出现条件与阶段变化，不每镜打卡、不新增道具、不泄密或干扰调度。

核对身份、关系、来源、习惯触发、年龄/疾病、逐字台词后，记录 character_bible_version；外观给资产，习惯给 acting_profile_id，声音给Voice，阶段状态给镜头卡。更新时使受影响下游失效；正式提示词只取当前镜头所需字段。

全剧人物资产需求判定

script_ready_gate通过、完整阅读全剧后，按人物逐项建立character_asset_plan，再进入资产制作。至少统计全剧／每集出场次数、涉及场次与shot、是否跨集复现、是否承担关键近景／动作接触／剧情辨认、服装状态数、发声行数与后续复用需要，并分别决定character_sheet_required与voice_reference_required；不以“有台词”自动推导必须建声音资产，也不以“有脸”自动推导必须生人物图。

核心／高频复现角色，以及虽出场不多但需要跨镜稳定辨认、近景呈现或承担关键接触的角色，按需要建立人物正面母版和完整四视角；同一角色是否需固定全局音色参考另行判定。执行默认阈值：跨集复现、在两个及以上clip出镜并要求跨clip保持同一外观，或全剧出现在3个及以上需辨认的shot，character_sheet_required=true；少于3个shot时，若同场包含近景身份辨认、关键身体接触或换装后仍需明确认出同一人，也设为true。全剧仅一个shot／单集一次、无后续复用且无跨镜辨认需求的跑龙套／背景人物，设为false。对白角色若在两个及以上clip／多集复用声音，voice_reference_required=true；只在一个clip／一次性场景发声且无后续复用，设为false。若剧情中的实际镜头需求与默认阈值冲突，允许按镜头风险调整，但必须在需求表说明具体shot／clip和理由，不用笼统“重要”作为建资产理由。

免建资产人物标记no_character_sheet、no_voice_reference：不生成专属人物资产图，不为声音母版提取音频；在视频提示词中依据人物卡／剧本用简洁且有辨识度的外貌与声音特征自由生成。同一clip中的多个shot须复用同一组简洁外貌／声音描述，不在镜头间换脸、换服装或换声线。群演优先按群组描述，不拆出无用个人资产。人物图与声音参考可独立判定，例如常露脸但不说话的角色可需人物图、不需声音母版；偶尔出场但跨多集重复发声的角色可需声音母版、未必需人物图。判定阈值只作一致执行基准，不替代镜头可读性判断。

对需要固定声音参考的角色，先在首次出场视频提示词中写明符合人物设定的音色、口音、年龄感及表达特征；该首次出场视频若没有该角色对白，不补造台词，改以最早有声出场视频作为voice_bootstrap。生成后只从实际听检合格的片段提取清晰单人语音，审核后登记并供后续视频参考。样本不合格时继续用文字声音设定，不得从混声、配乐或不清晰片段强行建样。

判定表至少包含：character_id、全剧／分集出场统计、叙事重要度、需要保持一致的镜头范围、服装状态、character_sheet_required及理由、voice_reference_required及理由、首次发声clip／line、首次提取状态、适用资产版本。判定为不需要资产也须记录理由，防止下游误认为漏做；剧本或复用范围改变时重审本表。

场景地图与空间图

从收到剧本开始建立全员关系与调度

步骤2建立并锁定制作剧本的角色关系／在场与基础调度台账，逐场登记全部角色、关系依据、谁向谁发声、可听见对象、到场／离场、剧本明确的位置和动作。区分人物社会关系、叙事知情关系、空间关系，不从站得近推断亲密，也不从远景缺席推断离场。有用户分镜时建立source_id→原镜号的映射并核对冲突；没有时按剧情节拍标记待细化，不假称已收到分镜。

步骤2已将未明确而不改变事件的站坐、朝向、相对距离、当前活动、行动路线与基础光线作为“制作补充”写入全稿并锁定。步骤6继承scene_baseline_version，细化共同地图、初始mark和空间尺度，给已有每次位置／姿态变化回填事件依据；不得直到步骤6才决定人物在干什么、光从哪里来；步骤8完成全剧逐镜调度表，所有角色必须有状态，不能只安排当前主角。原文确有集体背景人物时可用群组ID与区域记录，不虚构逐人身份和动作。

正式分镜输出前的调度确认门

正式分镜前先内部调度预演：按节拍及候选镜号核对全员世界位置、距离、朝向、站坐、视线、持物、遮挡、路线及相邻镜出入口。步骤6锁场次基准，步骤8候选稿上板前逐镜复核，步骤9节奏通过才发布正式稿；已有分镜先校正再修订，不把调度留到提示词或成片审查。

记录 pre_storyboard_blocking_gate=passed|failed|blocked、剧本／地图／调度版本、画幅、候选镜号、核对依据与未解决项。全员无遗漏、空间和接点唯一可执行、必要图证通过才可passed。确认指基于证据的制作复核，不强制用户逐镜点击；涉及剧情事实矛盾或不能代用户决定的选择，须先询问用户。

文字有多个合理空间解释、多人前后遮挡不明、接触／交叉路线不清或机位转换后投影无法唯一确定时，先补地标、世界方向、相对距离和动作起止。仍不能清楚表达就触发 depth_blocking_required=true：按02生成最少必要的人物调度深度参考图，逐图核验后反写清晰文字台账，再过本门；不得以“后期检查”或“模型自行理解”放行。

静态图不能证明动作连续。仅在已触发depth_blocking_required=true且涉及换位、绕行或接触时，按同一候选镜与摄影机分别制作起点、关键中间状态、终点的必要图，配文字时间顺序与路线；相邻镜按同一世界状态推导新机位图。画外人物继续按台账核对，不强行塞入画面。正式镜号确定后回填图证映射，禁止出现两套不一致的调度。

逐镜台账必须包含：

|镜号／角色|入口状态|本镜过程|出口状态|与下一镜的连接|
|---|---|---|---|---|
|episode／scene／shot／character_id、调度版本|在场／画内／画外／遮挡／尚未到场；mark或地标位置、站坐、身体朝向、视线对象、持物手位|动作触发、起点、路径、接触对象、速度趋势、终点；未动写保持；画外移动单独标记|世界位置、姿态／重心、动作相位、视线、道具状态及入／出画方向|next_shot、时间关系、下一入口、连续／画外移动／省略／新时空依据、核对结果|

画面左右另按每镜摄影机投影记录，不能代替世界位置。连续时间下，shot_01的终态须接上shot_02的起态；在动作中切时承接相容动作阶段，摄影机反打导致左右改变不算人物移动。任何位置变化须能从原文、已锁路线或合理画外过程解释，禁止每镜独立随机排位。全剧逐镜计划先锁，后续生成再用合格真实出点核验，不把计划终态当成实际已发生。

未出镜例外：画外者不要求有可见的逐帧位置证据，可以按已登记的时间与路线完成未展示移动，标为“计划画外状态／未直接观察”。未初登场者无需与此前画面匹配，但首次入画位置、方向与入口须成立；已出画者再次出现时核对耗时、路线、姿态和道具，不能以“上一镜没拍到”为由穿墙、瞬移或重置状态。影响下一镜接触／位置的未知项必须先解决，不能伪填已观察。

横版与竖版的分镜适配

分镜定稿前核对各镜scene_view_asset_id的format_version和实际比例：横版镜头绑定横版场景图，竖版镜头绑定竖版场景图，指定其他比例亦同。双版共用世界地图但分别生成场景视图，不把横图引用留给竖版视频自行裁切。必要人物深度图同步匹配该版画幅与机位；缺少对应版合格场景图时不得将受影响分镜标为可执行定稿。

每镜注明format_version、landscape／portrait及实际宽高比，再决定摄影机位置、景别、主体占比和动作范围。横版检查并列人物、侧向行进和空间层次；竖版检查窄画幅中谁能同时看清、手部／脚步是否出框及视线空间。必要时调整机位、景别或拆覆盖镜，但不能为画幅变更角色世界站位、事件或台词。需要同镜看清的关键交接不能拆到看不懂接触。

双版沿用共同shot父ID，分别写L／P取景与必要覆盖子镜、切点和资产视角对应。一个版本重新设计后重验动作、声音与衔接，不自动将另一版本判为通过。画外UI／字幕安全区只按明确交付平台或用户要求设置，无依据不捏造统一像素边距。

场景图板的主视角、反向与少量细节必须共同对应本节同一地图。为各视角登记机位、可见地标和细节所在区域；确认门窗、路线、高差、固定物体的连接与尺度相容。正式图内只留短标签，详细空间说明放在地图和制作记录中；不得靠多堆几个独立美图代替空间关系。

每个正式场景都建立与项目画幅一致的已验主视角和由主图真实参考生成的同源反向视角；即使当前分镜暂时不用反打，也保留这组基础资产。对确有路线、动作接触、地标或主反图无法覆盖的部分补必要视角。

每个主要场景建立 scene_map_id：轮廓、入口、墙面/固定家具/关键道具/通路；MAIN VIEW与世界方向；每人 mark_id、站坐、朝向、视线、距离；遮挡/接触/道具手位；摄影机世界位置、关系轴/轴线侧及画内投影；真实光源世界位置；每次移动的依据、触发、起点、路线、终点和结束姿态。

以下任一成立时建立可核验 spatial_blocking_version（优先俯视SVG）：同空间两人以上；关键道具有固定表面/持有人；机位几何、遮挡、轴线、接触或路线影响叙事；用户改了位置。图上标人物、视线、道具、距离/表面、MAIN VIEW、世界方向、关系轴、机位。单人普通特写、无关系插镜、纯环境可省略空间示意图，但不能省略适用的全员调度台账与逐镜衔接检查。位置已唯一确定可内部复核；仅有结果性歧义或用户明确要求时才逐镜确认。

分镜/提示词从最新空间图转写：世界方向、绝对位置/mark、姿态/视线/遮挡/接触、摄影机位置/轴线侧/画内方向、允许位移及路线。画外/遮挡人物仍保留位置；换机位不授权人物换位。

每个切点标 continuous_time / action_ellipsis / time_space_reestablish / parallel_cut / 原文支持的montage，并记录：

continuityIn/Out / transitionMethod / axisSide / screenDirection
keyLightWorldDirection / entry/exitPosition / entry/exitPose
entry/exitActionPhase / propAndHandState / actingStateIn/Out
acting_profile_id / line_id / audioSourceOffset / speakerInFrame / mouthVisible

若使用 parallel_cut（交叉剪辑／平行行动），先登记每条action_line_id（行动线唯一编号）、episode_id、scene_id、地点、人物、各自目标、行动开始与预计结束时间、观众已知信息和最终汇合／不汇合结果，并明确它是“同时发生”还是“跨时间对照”；不确定同步关系时不得写成同时发生。每个镜头以episode_id + scene_id + shot_id唯一定位，另关联action_line_id；不得用可能跨集重复的单独shot_id或对白line_id替代。逐shot写出正在发生的可见动作、关键物件／地标、当前结果和切出点；交替次序与每次切回带来的新信息要能读懂。切换时优先在动作、声音或信息节点上形成因果／对照关系，不按固定A-B-A-B次数机械切，也不重复同一信息凑镜头。各行动线分别维持自己的场景地图、轴线、人物／道具状态和世界光源；切回时按本线前一shot出口承接。使用声音跨接时记录声音来源、进入／退出点和听觉所在空间，不能让声桥误导观众对同时性或位置的判断。若只是压缩某段时间或作主题联想而非交替呈现多条行动线，标记为montage并写明省略了什么时间、保留哪些因果，不冒称parallel_cut。

不得为错误素材把连续时间改称省略/蒙太奇；动态观看动作过程；审查截图只作qa_only辅助，不进入下一段生成。
